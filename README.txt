EYMEN HOME LAUNCHER

1) GitHub'da mevcut eymen-galactic-os deposunu aç.
2) Add file > Upload files seç.
3) Bu ZIP'in içindeki TÜM dosya ve klasörleri yükle (ZIP'in kendisini değil).
4) Commit changes.
5) Depoda Actions sekmesine gir.
6) Build EYMEN APK iş akışını aç; gerekirse Run workflow'a bas.
7) İşlem bitince tamamlanan çalışmayı aç, Artifacts bölümünden EYMEN-APK dosyasını indir.
8) ZIP'i telefonda aç, app-debug.apk dosyasını kur.
9) Kurulumdan sonra Ayarlar > Uygulamalar > Varsayılan uygulamalar > Ana ekran uygulaması > EYMEN seç.

Not: Bu Android Studio/GitHub Actions kaynak projesidir; APK bu ortamda derlenmedi.
